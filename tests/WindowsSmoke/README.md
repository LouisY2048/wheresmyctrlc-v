# Windows 原生输入烟雾测试

这是一个不依赖测试包的集成测试程序。只有加 `--run` 才会发送模拟键盘输入：

```powershell
dotnet run --project tests/WindowsSmoke -- --run
```

测试会开启独立子进程的两个无害文本框，只向已验证属于该子进程的窗口发送输入，不向终端发送命令。请关闭 Caps Lock、松开修饰键，并在约 10 秒的测试期间不要操作鼠标键盘。Windows 拒绝切换到测试窗口时测试会失败，不会继续向其他窗口发送按键。

覆盖全部 95 个可打印 ASCII、前后空格、Unicode 中文和 emoji、CRLF/CR/LF、显式追加回车、非法字符整段拒绝、默认禁止末尾换行、取消时释放 Shift，以及切换窗口后停止。接收端通过当前用户专用命名管道报告文本和 Enter 次数，测试不依赖屏幕 OCR。

接收端在创建窗口前调用 `ImmDisableIME(0)`，仅禁用测试子进程 UI 线程的输入法，避免中文输入法改写测试符号。不会加载、安装或更改系统键盘布局。测试失败时输出完整异常堆栈，清理子进程和管道时不会覆盖原始失败原因。

此测试验证本机 `SendInput` 行为。实际 iBMC、RDP、浏览器控制台的兼容性仍需在对应环境中检查。Windows 可能因前台激活策略而拒绝运行，程序会明确报错。
